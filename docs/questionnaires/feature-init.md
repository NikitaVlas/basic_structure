# Feature initialization questionnaire

Allowed answers: a concrete answer, `Unknown`, `Propose options`, or
`Not applicable`.

## Outcome

1. What should be added or changed?
2. What problem does this solve?
3. Who will use it?
4. What is the expected successful outcome?
5. What is explicitly outside scope?

## Behavior

6. How does the system behave now?
7. Describe the primary successful scenario.
8. Which alternative and failure scenarios matter?
9. What inputs, outputs, and validation rules apply?
10. Which edge cases must be handled?

## Contracts and data

11. Does this change a public API, schema, event, or command?
12. Does it add or modify stored data?
13. Is backward compatibility required?
14. Are migrations or rollback procedures needed?

## Security and operations

15. Which roles and permissions apply?
16. Is sensitive data involved?
17. Which logs, metrics, or audit events are required?
18. How should dependency, timeout, and partial failures behave?

## Interface

19. Is there a user interface?
20. Is an approved design or Figma frame available?
21. Which responsive, accessibility, and UI states are required?

## Delivery

22. What constraints or prohibited changes apply?
23. What are the acceptance criteria?
24. Which tests and manual checks are expected?
25. Which decisions require approval before implementation?
