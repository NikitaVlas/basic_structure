# Architecture initialization questionnaire

Allowed answers: a concrete answer, `Unknown`, `Propose options`, or
`Not applicable`.

1. What type of application is being built?
2. Which architectural style is used or preferred?
3. What are the main modules and their responsibilities?
4. Which dependencies between modules are allowed or prohibited?
5. Where does business logic belong?
6. How is data accessed and who owns it?
7. How do authentication and authorization work?
8. How are errors represented and handled?
9. How is configuration loaded and validated?
10. How are schema and data migrations performed?
11. How are logging and observability handled?
12. Which external systems are integrated?
13. How is the system built, deployed, and rolled back?
14. Which architectural decisions remain open?
15. Which future changes require a separate ADR?
16. What compatibility guarantees must be preserved?
17. What are the principal trust and failure boundaries?
