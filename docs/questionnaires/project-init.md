# Project initialization questionnaire

Allowed answers: a concrete answer, `Unknown`, `Propose options`, or
`Not applicable`.

## Product

1. What is the project called?
2. What problem does it solve?
3. Who are its users?
4. What is the primary user journey?
5. What stage is the project in?
6. What belongs in the first version?
7. What explicitly does not belong in the first version?
8. How will success be measured?

## Existing state

9. Does code already exist?
10. Is this a new or legacy project?
11. Which parts already work?
12. What known problems exist?
13. Are documentation, designs, or API contracts available?

## Technology

14. What stack is used?
15. Which technologies are mandatory?
16. Which technologies are prohibited?
17. Where will the application run?
18. Which external services are used?
19. What data is stored?

## Users and security

20. Which roles exist?
21. Is authentication required?
22. How are permissions determined?
23. Is sensitive data processed?
24. Are there legal, compliance, or security requirements?

## Constraints

25. What deadlines exist?
26. Are there budget limits?
27. Is backward compatibility required?
28. Which system parts must not change?
29. Which agent actions require approval?
30. What may the agent do autonomously?

## Quality

31. Which test types are expected?
32. Which browsers, devices, or platforms are supported?
33. Are there performance requirements?
34. Are there accessibility requirements?
35. Which checks are mandatory before a task is complete?
