## How to use the catalog

For UI work, select only the patterns relevant to the task. For each selected pattern, record: user task, observed risk, applicable UI decision, ethical boundary, and validation method. Use the original KeepSimple article as the source for its definition and examples; this file is an index and working contract, not a replacement for the source.
